# PikPak for fnOS 安装与验证

面向 fnOS（飞牛）x86 设备的安装说明。应用装在飞牛上，通过桌面图标打开；每个飞牛用户绑定自己的 PikPak 账号，互相看不到对方的文件。

安装包：`pikpak-<版本>-x86.fpk`（例如 `pikpak-1.0.0-x86.fpk`），来自 [Releases](../../releases) 或本地 `make fpk`。

## 1. 把安装包传到飞牛

任选一种：

- **文件管理器**：通过 SMB / WebDAV / 飞牛文件管理把 `.fpk` 上传到任意目录（例如 `个人空间/下载`）。
- **SSH / scp**（如已开启 SSH）：

  ```bash
  scp dist/pikpak-1.0.0-x86.fpk <用户名>@<飞牛地址>:/tmp/
  ```

## 2. 安装

1. 飞牛桌面 → **应用中心** → 右上角菜单 → **手动安装**，选中 `.fpk`。
2. 应用名显示为 **PikPak**。
3. 若提示"未签名 / 来源不受信任"：本仓库未配置开发者证书时构建的包不带签名，需要在飞牛里允许安装第三方应用，或改用带签名的包（仓库 Secrets 配好 `FN_DEVELOPER_KEY` / `FN_DEVELOPER_CERT` 后由 CI 签名）。

安装后的位置（排查用，以飞牛实际挂载为准）：

| 内容 | 典型路径 |
|---|---|
| 程序 | `${TRIM_APPDEST}`，形如 `/var/apps/pikpak/target` |
| 数据（SQLite、密钥、日志） | `${TRIM_PKGVAR}`，形如 `/var/apps/pikpak/var` |
| 日志 | `${TRIM_PKGVAR}/logs/app.log` |
| 本地通信 | `${TRIM_APPDEST}/app.sock`（0600，不监听 TCP） |

## 3. 打开应用

从飞牛桌面点击 **PikPak** 图标。页面挂载在统一网关下（`/app/pikpak`），左侧是功能导航：

**我的文件 · 最近 · 回收站 · 传输 · 离线任务 · 全网搜索**（设置在最下方）

> 必须通过飞牛桌面打开。直接访问端口或把地址发给别人不会工作：身份只认飞牛网关注入的 `X-Trim-Userid`。

## 4. 绑定 PikPak 账号

首次打开会提示"尚未绑定 PikPak 账号"：

1. 点 **绑定账号**（或进 **设置 → 账号 → 重新授权**）。
2. 页面显示用户码和 `mypikpak.com` 链接；用浏览器打开链接并确认用户码。
3. 页面自动轮询，授权成功后显示"已绑定"。

凭据用 AES-256-GCM 加密存在本机 SQLite，只属于当前飞牛用户。绑定使用 OAuth 设备码而不是个人访问令牌，因为清空回收站需要 OAuth 才能拿到的 `files:purge` 权限。

## 5. 常用功能

### 文件

- 浏览、进入文件夹、面包屑返回、网格/列表切换。
- 选择按 Finder 的规则：单击单选，`Command`（Mac）/ `Ctrl`（Windows）单击切换多选，`Shift` 单击选一段，在空白处拖动框选，`Command/Ctrl + A` 全选，`Esc` 取消。
- 新建文件夹、重命名、移动（拖拽或右键菜单）、复制、删除（进回收站）。
- 名称筛选与类型筛选只作用于已加载的条目；列表接口不支持服务端排序/搜索，这一点在页面底部有说明。搜索整个 PikPak 账号请用 **全网搜索**。

### 离线任务

- 新建：粘贴磁力链接或 URL，等 PikPak 云端下载完成。
- 按状态筛选、重试失败任务、删除任务（可勾选同时删除已下载文件，默认不勾）。
- 每日离线额度用完时显示"离线任务每日额度已用完，请明天再试"，不会自动重试。

### 传输

- **下载到…**：把 PikPak 文件下载到飞牛上的目录。只能写当前飞牛用户有权限的目录（文件选择器或绝对路径）。
- **上传**：从飞牛目录选文件上传到 PikPak 当前目录。
- 传输页显示进度、速度、剩余时间；可暂停/继续/取消；重名策略在设置里选（重命名 / 跳过 / 覆盖）。
- 同时下载数由全局并发上限控制（默认 2，最高 4）。

### 回收站

- 列出、还原、永久删除单个文件，或清空回收站。

### 播放

- 文件菜单里对视频点 **播放**：内置播放器支持全屏、0.5×–2× 倍速、下载。
- 默认走**代理**模式：签名下载地址只留在后端，浏览器拿到的是本站地址，拖动进度条由 CDN 按 Range 响应。
- 不做转码。浏览器不支持的编码（常见如部分 MKV 封装）会明确提示"浏览器不支持该编码，可下载后使用本地播放器观看"。

### 全网搜索

- 通过搜索引擎查找 `mypikpak.com` 上的**公开分享页**。只输入关键词即可，`site:` 限定由服务端自动拼接。
- 依赖一个搜索服务 API Key（默认 Serper，返回 Google 结果）：在 **设置 → 参数设置 → 全网搜索 API Key** 里填写，可在 serper.dev 免费申请。Key 只存在本机数据库，读取设置时不会返回，也不会写进日志。
- 结果在应用内标签页打开（标题栏下方出现标签页，可关闭、可切换回“搜索结果”），不再跳到浏览器；右键标签页可以复制地址。
- 每页 10 条，最多 10 页；每次翻页都会消耗一次搜索服务的额度。搜索引擎只收录公开分享，自己账号里**未分享**的文件和文件夹搜不到。

### 设置与诊断

- 账号：重新授权、解绑（解绑会删除本机凭据并清除本用户的传输任务记录，已下载文件保留）。
- 参数设置：重名策略、默认下载目录、全局同时下载数（重启后生效）、全网搜索 API Key、播放方式（代理 / 跳转）、界面语言（中文 / English）；保存按钮在卡片右上角。
- 已授权的共享文件夹：下载与上传只允许写这些目录及其子目录。
- 关于：版本、数据库大小、任务数、最近错误摘要。

## 6. 升级

直接用手动安装覆盖安装新版本。数据目录 `${TRIM_PKGVAR}` 不会被替换，绑定关系、设置、任务记录、授权目录都保留。

登录态失效时（PikPak 侧撤销授权等），应用顶部会出现常驻提示"PikPak 授权已失效"，按提示重新绑定即可。

## 7. 卸载

**应用中心 → 已安装 → PikPak → 卸载**。卸载会删除 `${TRIM_PKGVAR}`（数据库与密钥），需要重新绑定。已经下载到飞牛上的文件不受影响。

## 8. 排障

| 现象 | 处理 |
|---|---|
| 页面空白或 404 | 确认是从飞牛桌面打开（走 `/app/pikpak` 网关），而不是直接访问端口 |
| 接口返回 401 | 网关没有注入 `X-Trim-Userid`；确认从桌面内打开应用 |
| 接口返回 400 且提示身份头重复 | 网关保留了客户端伪造的 `X-Trim-Userid`，这是安全拦截，属预期行为 |
| 顶部提示"PikPak 授权已失效" | 在设置里重新绑定 |
| 绑定页一直"等待授权" | 用户码 5 分钟后过期，重新发起即可 |
| 下载到飞牛失败（403） | 目标目录不在当前飞牛用户的授权目录内，或没有写权限 |
| 上传 403 | 源文件不在授权目录内，或没有读权限 |
| 播放提示编码不支持 | 预期行为（不转码），用下载按钮保存后本地播放 |
| 全网搜索某页没有结果 | 该关键词在 Google 收录里就这么多；翻页不会变出更多，回到第 1 页换个关键词 |
| 全网搜索提示需要 API Key | 在 **设置 → 参数设置** 填写 Serper Key；提示 Key 无效则检查是否复制完整 |
| 下载速度慢 | 单用户受 PikPak 限流；并发上限可在设置里调整（重启生效） |

看日志（每个请求一行，含方法、路由、状态码、UID 与耗时，不记录令牌与签名地址；单文件 10 MiB，最多保留 5 份）：

```bash
tail -n 200 /var/apps/pikpak/var/logs/app.log
```

调试页与探针接口默认关闭。需要排查网络/网关时，在启动参数里加 `--debug`（调试页入口随之出现），排查完请去掉。

## 9. 真机验证清单

发布 1.0.0 前在一台真实 fnOS 设备上逐项确认，全部通过再打 tag：

- [ ] **安装**：手动安装 `.fpk` 成功，应用中心显示 PikPak 与正确版本号。
- [ ] **启动**：桌面打开后页面正常加载，`${TRIM_APPDEST}/app.sock` 权限为 0600，进程非 root。
- [ ] **绑定**：设备码流程完成，刷新页面仍显示已绑定；重启应用后仍保持绑定。
- [ ] **双用户隔离**：用两个飞牛用户分别绑定不同 PikPak 账号，A 看不到 B 的文件、任务、设置。
- [ ] **授权目录写盘**：把 PikPak 文件下载到授权目录成功，文件内容正确（比对大小或校验和）；对未授权目录的写入被拒绝。
- [ ] **上传**：从授权目录上传到 PikPak 成功，PikPak 中文件大小一致。
- [ ] **Range 播放**：播放一个较大的视频，能拖动进度条并继续播放；`curl -r 0-99` 的响应是 206。
- [ ] **升级保留数据**：覆盖安装新版本后，绑定、设置、任务记录、授权目录都还在。
- [ ] **错误提示**：断开代理或制造一次接口失败，页面右下角出现可展开详情的错误提示，文案为中文。

## 10. 安全约定

- 只监听 `${TRIM_APPDEST}/app.sock`，不监听 TCP。
- 身份只来自飞牛网关注入的 `X-Trim-Userid`；缺失 401，重复 400，绝不从请求参数取 uid。
- 不以 root 运行。
- 令牌、设备码、签名下载地址不进日志、前端或错误提示详情；数据库与密钥文件为 0600。
- 默认代理播放，签名地址不离开后端；改成"跳转"模式时浏览器会直连 PikPak CDN，请自行权衡。
